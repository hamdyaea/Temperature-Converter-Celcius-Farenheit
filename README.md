# Temperature Converter

Convert Celsius and Fahrenheit accurately, with a simple desktop interface.

Developer: **Hamdy Abou El Anein**  
Contact: **info@daylightlinux.ch**  
License: GNU GPL v3 (see LICENSE).

## Features

- Lightweight Python 3 + Tkinter GUI; no EasyGUI dependency.
- Input validation and testable functions.
- Original source preserved on the [old branch](https://github.com/hamdyaea/Temperature-Converter-Celcius-Farenheit/tree/old).

## Run

    python3 TempConverter.py

## Tests

    python3 -m unittest discover -s tests -v
